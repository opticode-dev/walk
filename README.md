# Campus Walk（激辛ハチワレ）

通学時間を、ちょっと楽しい時間にするためのハッカソン用プロトタイプです。

## ローカルで実行

Python 3.10 以降を用意し、リポジトリのフォルダで次を実行します。

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud で公開

1. このリポジトリを GitHub に push します。
2. Streamlit Community Cloud で GitHub リポジトリを選びます。
3. Main file path に `app.py` を指定して Deploy します。

## 現在の実装範囲

- プロフィール編集
- オンライン／オフライン切り替え
- デモ用の通学仲間の検索・プロフィール表示
- マッチ希望の送信
- デモ用の承認・辞退
- マッチ成立後のチャット画面

## 重要な制約

このバージョンは発表用のデモです。ユーザー情報は Streamlit のセッション状態に保持され、他の端末やユーザーとは共有されません。位置情報はサンプルデータで、GPSを取得・送信していません。チャットも同じセッション内のデモです。

複数ユーザーで本当に利用するには、認証、共有データベース、位置情報取得の仕組み、リアルタイム更新、通報・ブロックなどの安全機能を追加する必要があります。位置情報は必要以上に正確な値を公開せず、ユーザーの明示的な同意を得て扱ってください。
